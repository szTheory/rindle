## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host migration keyword opts -&gt; Rindle DDL | Untrusted host migration options select version and prefix. |
| Rindle DDL -&gt; Postgres schema | Migration helpers create, alter, index, and drop database objects. |
| legacy packaged migration -&gt; host Oban table | Historical migration file must not own shared host Oban state. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-116-13 | Tampering | `Rindle.Migration.Options` | mitigate | NimbleOptions validation and tests reject invalid versions, prefixes, and unknown options. |
| T-116-14 | Tampering | prefix-aware DDL | mitigate | All table/index/reference/catalog-facing helpers receive the selected prefix; default remains `public`. |
| T-116-15 | Tampering / Denial of Service | destructive rollback | mitigate | `down/1` drops only the Rindle-owned table list and marker table in dependency order. |
| T-116-16 | Tampering | bundled Oban migration | mitigate | Legacy file becomes no-op compatibility stub with tests proving no `oban_jobs` ownership. |
| T-116-SC | Tampering | package installs | accept | This plan adds no package-manager installs and uses locked dependencies. |
</threat_model>
