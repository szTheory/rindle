## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Postgres catalog -&gt; doctor/runtime reports | Database readiness observations become operator-facing status. |
| legacy migration history -&gt; repair guidance | Existing applied histories must not trigger destructive repair advice. |
| host-owned Oban -&gt; Rindle runtime | Rindle reads Oban readiness without owning or mutating Oban tables. |

| T-116-18 | Tampering | legacy drift guidance | mitigate | Healthy legacy drift is warning/history-only; no delete/replay guidance. |
| T-116-19 | Information Disclosure / Repudiation | runtime-status DB errors | mitigate | Setup preflight returns bounded structured errors before undefined-table crashes. |
