<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Snapshot result to report-query execution | A mistaken ready state can send queries into absent or attacker-selected schemas. |
| Runtime failure term to CLI text/JSON | Arbitrary adapter terms may contain SQL, connection details, or credentials. |
| Resolved Oban prefix to Ecto queries | Host config selects a dynamic query prefix only after snapshot validation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-119-09 | Tampering | Oban report prefix routing | high | mitigate | Thread only snapshot-validated default-host prefix into Oban queries; keep Rindle queries on compile-time authority; prove split-prefix routing. |
| T-119-10 | Denial of Service | report execution after refusal | high | mitigate | Place snapshot interpretation before every report helper and use a raising tripwire for all refusal classifications. |
| T-119-11 | Information Disclosure | text/JSON formatter | high | mitigate | Explicit bounded clauses plus constant unknown fallback; sentinel leakage tests cover stdout, stderr, and JSON. |
| T-119-12 | Tampering | runtime remediation temptation | medium | mitigate | Return diagnostics only; no migration, queue, lifecycle, or application-env mutation is callable from the refusal path. |
| T-119-SC | Tampering | package installs | high | mitigate | No package install is planned; stop for legitimacy audit and human review if execution proposes one. |
</threat_model>
