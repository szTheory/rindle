<interfaces>
- Fresh: `Rindle.Migration.up(version: 1)` defaults to `rindle`; explicit compatibility is `Rindle.Migration.up(version: 1, prefix: "public")` paired with a public-compiled release.
- Upgrade up: host Ecto migration sets `SET LOCAL lock_timeout`, then calls `Rindle.Migration.move_public_to_rindle(version: 1)`; after successful public-source preflight, the helper creates an absent `rindle` schema inside that transaction before the first table move.
- Upgrade down: only while exactly reversible, host Ecto migration sets the same local timeout and calls `Rindle.Migration.move_rindle_to_public(version: 1)`; `Rindle.Migration.down/1` is destructive teardown.
- Rindle owns six domain tables plus `rindle_migration_versions`; the host owns `oban_jobs`, Oban prefix/configuration, and `schema_migrations`.
</interfaces>
