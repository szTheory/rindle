|----------|-------------|
| Rindle macro to consuming schema module | Consumer module code can mutate or delete ordinary module attributes between `use Rindle.Schema` and Ecto schema declaration. |
| Rindle-owned schemas to shared host Repo | Selected Rindle metadata must qualify only Rindle domain tables without becoming a Repo-wide or Oban prefix. |
| Compile/release configuration to runtime deployment | The selected prefix is embedded during compilation; runtime-only configuration cannot safely switch an already-built release. |
