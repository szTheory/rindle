## Trust Boundaries

| Boundary | Description |
|---|---|
| Runtime error to admin facade/assigns | Internal terms can become HTML-visible if the facade forwards raw reasons. |
| Runtime error to adoption demo HTML | Demo interpolation can bypass the supported task formatter and disclose adapter details. |
| Operator presentation to host ownership | UI affordances or ambiguous text could imply Rindle owns migration, Oban, queues, or ledger state. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-119-13 | Information Disclosure | admin facade and LiveView | high | mitigate | Project only bounded diagnostic fields, remove raw-reason assigns, and assert sentinel details are absent from maps and HTML. |
| T-119-14 | Information Disclosure | adoption demo error branch | high | mitigate | Delegate to shared `format_error/1`; a deterministic LiveView event/render test injects SQL/Postgrex/credential sentinels and proves they never render. |
| T-119-15 | Tampering / Elevation | operator controls and ownership copy | high | mitigate | Keep surfaces read-only, add no repair controls, and explicitly name host-owned migration/Oban responsibilities. |
| T-119-16 | Repudiation | status conveyed by presentation | low | mitigate | Preserve stable IDs, deterministic ordering, and explicit status words so meaning is not color-only or ambiguous. |
| T-119-SC | Tampering | package installs | high | mitigate | No dependency change is planned; any install requires legitimacy audit and blocking human review. |
</threat_model>
