## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| persisted receipt -> verifier | Every stored JSON field is attacker-controlled until reconstructed or independently rebound. |
| GitHub API/logs -> canonical reconstruction | Remote responses may be malformed, incomplete, duplicated, stale, or from the wrong run/job. |
| local authority status -> receipt | A stored green string can impersonate census/live-truth execution unless tied to fixed validators and subject SHA. |
