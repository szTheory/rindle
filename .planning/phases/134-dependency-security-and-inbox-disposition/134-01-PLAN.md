## Inventory interface (consumed by Plans 03, 04, 05, 06)

Top-level keys of the JSON written by `collect_inbox.sh --out FILE` (sorted with `jq -S`):
- `schema`: literal `rindle-inbox-inventory-v1`; `collected_at`: ISO-8601 UTC from the injectable clock; `repo`; `main_sha`.
- `issues[]`: `{number, title, labels[], updated_at}` (PRs filtered out of the issues endpoint with `.pull_request == null`).
- `prs[]`: `{number, title, author, base, head_sha, mergeable, mergeable_state, behind (bool), ci_summary: {conclusion, completed_at, check_run_id, superseded_count} or {conclusion: null, reason: "no_check_runs"}, manifest_files[], lock_delta[] of {lock, package, from, to}}`. `mergeable` stays `"unknown"` after bounded retries, never coerced.
- `terminal[]`: one `{number, kind, state, state_reason, merged}` per `--include N` argument.
- `hex_latest{}`: package -> latest released version, one per `--hex-package NAME` argument, via `mix hex.info NAME`.
- `advisories`: `{sources: {hex_audit_root, hex_audit_demo, deps_audit, dependabot_alerts, vulnerability_alerts, actions}, findings[] of {id, package, version, severity, scope ("root" or "examples/adoption_demo"), source, ignored}}`. Source status vocabulary: `clean | findings | enabled | source_disabled | unreadable | not-applicable`, each with `http` where applicable. `actions` is `{status: "not-applicable", reason: "SHA-pinned actions produce no alerts"}`.
- `branch_protection`: `{source: "protection" | "branches-partial" | "unreadable", http, contexts[], strict (bool or "unreadable"), enforce_admins (bool or "unreadable")}`.
- `main_ci`: `{run_id, head_sha, conclusion, failed_jobs[]}` for the latest `ci.yml` push run on main.

CLI: `collect_inbox.sh --out FILE [--repo OWNER/NAME] [--include N]... [--hex-package NAME]... [--skip-demo-audit]`. Clock injection: `INBOX_NOW_EPOCH`. Exit 0 = inventory written; exit 1 = collection failure, no file; exit 64 = usage. `--skip-demo-audit` records `hex_audit_demo` as `{status: "unreadable", reason: "skipped"}` (never `clean`).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub API to collector | PR titles, branch names, labels and patches are attacker-controllable text |
| hex.audit/mix output to collector | Human-format text parsed into JSON |
| Maintainer admin token to script | Token can write; script must only read |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-134-01 | Tampering | collect_inbox.sh handling of titles/labels/patches | high | mitigate | All values pass through `jq --arg/--argjson`; no eval or unquoted expansion; strict sed patterns for lock lines |
| T-134-02 | Elevation of privilege | gh calls with admin token | high | mitigate | Single gh_get wrapper with no method flag; harness mutation tripwire fails on any write method or mutating verb |
| T-134-03 | Repudiation | advisory sources reported as zero | high | mitigate | Explicit source_disabled/unreadable records; hex.audit run with ignores emptied; unparseable output aborts |
| T-134-04 | Spoofing | stale or partial inventory replay | medium | mitigate | collected_at and main_sha in every inventory; atomic temp-file plus mv; any page failure exits 1 with no file |
| T-134-05 | Information disclosure | protection/alerts reads in logs | low | accept | Only repo-level metadata already visible to admins is written to a local scratch path |
| T-134-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installs in this plan; demo deps fetched lock-verified into a scratch path and both locks checked unchanged |
</threat_model>
