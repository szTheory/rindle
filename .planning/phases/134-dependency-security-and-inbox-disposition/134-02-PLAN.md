## dep_landing_evidence.sh interface (consumed by Plans 03, 04, 05)

`dep_landing_evidence.sh --sha SHA [--group NAME --packages a,b,...] [--lock PATH] [--baseline-sha SHA] [--repo OWNER/NAME] [--out FILE]`
- `--lock` defaults to `mix.lock`; `examples/adoption_demo/mix.lock` is the other allowed value. Without `--group`, the tool runs in baseline mode (gates only, no attribution).
- Output JSON (`jq -S`): `{schema: "rindle-dep-landing-v1", sha, group, lock, lock_delta[] {package, from, to}, mix_exs_changed, attributable, run {id, head_sha, event, status, conclusion}, baseline_run {id, head_sha} or null, gates {supported_toolchain, public_contract, package_consumer, twin}, jobs[] {name, conclusion, gate, baseline_conclusion, class}, verdict}`.
- Gate values: `pass | fail | missing | inherited_red`. Twin is always `not-applicable: twin not built (Phase 137)`.
- Exit codes: 0 pass (attributable when grouped, all gate jobs success); 1 regression, attribution failure or missing gate job; 3 inherited_red only; 75 run absent or not completed; 64 usage.
- Gate job map (exact names, or name followed by " (" for matrix legs; verify against ci.yml `name:` keys before coding): supported_toolchain = `Quality (`, `ADMIN-06 Optional Dependencies (`; public_contract = `Contract`, `Proof`, `Integration`, `CI Script Tests`; package_consumer = `Package Consumer Proof Matrix + Release Preflight`, `Adopter`, `Adoption Demo Unit`, `Adoption Demo E2E Smoke`, `Package Consumer Full Matrix + Release Preflight (`, `Cohort Demo Smoke`, `Adoption Demo E2E`. Every exact name must be present and every prefix must match at least one job, else `missing`.

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-134-06 | Tampering | dependency group landing | high | mitigate | Script-computed lock delta must be a subset of declared group packages and mix.exs must be unchanged, else exit 1 |
