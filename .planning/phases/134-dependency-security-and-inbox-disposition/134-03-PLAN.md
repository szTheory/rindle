## Ledger schema (rindle-inbox-ledger-v1)

Top level: `schema`, `repo`, `items[]`, `advisories[]`, `sources{}`, `landings[]`.
- item: `kind` (issue|pr), `number`, `disposition` (merge|close|retain|supersede|defer), `rationale`; PRs carry `head_sha` (40-hex) unless `terminal` is present; optional `pending_action` (rebase|close|merge), recorded and never credited; `supersede` needs `successor`; `defer` needs `gate` and `trigger`; dependency PRs carry `risk_group` and `group_packages[]`; `terminal` is `{state: "closed", merged: bool, state_reason}` and must equal the inventory's terminal lookup.
- trigger: `{type: "date", not_after: "YYYY-MM-DD"}` fires when now is after not_after; `{type: "hex_version_gte", package, version}` fires when inventory `hex_latest[package]` is at or above version (dotted numeric compare in jq); `{type: "gh_issue_closed", number}` fires when the inventory terminal lookup shows closed. A fired trigger on a defer item or exception rejects with "trigger fired: re-decide".
- advisory: `id`, `package`, `locked`, `scope` (root|examples/adoption_demo|github), `path[]`, `reachability` (runtime|dev-test-only|optional-dep), `fix_version` (string or null), `status` (resolved|exception|open), `exception` `{expires: "YYYY-MM-DD", trigger, rationale}` when status is exception.
- sources: `dependabot_alerts` `{status, rationale}`.
- landing: `number` (PR), `group`, `group_packages[]`, `lock`, `merge_sha`, `ci_run_id`, `baseline_run_id`, `lock_delta[]`, `gates{supported_toolchain, public_contract, package_consumer, twin}`, `subject`.

CLI: `validate_inbox_ledger.sh --ledger FILE (--offline | --inventory FILE [--max-age-seconds N])`, plus `--print-collector-args --ledger FILE`. Clock: `INBOX_NOW_EPOCH`. Exit 0 valid, 1 rejected (each reason on stderr prefixed `REJECT:`), 64 usage.
