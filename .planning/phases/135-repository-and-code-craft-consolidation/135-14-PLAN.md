## Regex

Replace the phase-ref pattern at `scan_live_residue.exs` line 56 with `~r/(?i:(?<![a-z0-9])phase[_ -]?\d{1,3}(?!\d))|(?<=[a-z0-9])Phase\d{1,3}(?!\d)/`. The first branch is case-insensitive and allows a leading `:`, `@`, `_`, quote or space but not a letter or digit (so `multiphase 2` is clean). `(?!\d)` replaces the old trailing `\b`, which never matched inside `phase_120_x` because `0_` is not a word boundary. The second branch is case-sensitive and catches a CamelCase module segment. The class name stays `phase-ref`, so existing phase-ref allowlist keys still match.
