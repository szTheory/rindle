## Script contract

- Modes: default local, `--release-prep` (local plus BLOCK on ahead and on the publish race), `--ci` (no fetch, branch, drift or mix ci; runs repo-owned checks, tracked junk and the ledger offline validator). `--with-mix-ci` adds `check_mix_ci` in local or release-prep mode.
- Env: `RINDLE_HYGIENE_ROOT` (default `git rev-parse --show-toplevel`), `RINDLE_HYGIENE_REMOTE` (existing, default origin), `RINDLE_HYGIENE_BRANCH` (default main).
- Order in local and release-prep: snapshot residue (`git status --porcelain=v1 -uall --ignored`), check_fetch, check_branch, repo-owned checks, check_tracked_junk, check_generated_drift, check_mix_ci (when requested), check_residue (second snapshot and delta).
- Exit codes unchanged: 0 safe or caution, 1 not ready, 64 usage.
