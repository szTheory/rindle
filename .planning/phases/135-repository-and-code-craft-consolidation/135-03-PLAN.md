## Ledger schema (rindle-artifact-ledger-v1)

- Top level: `schema`, `classes[]`, `ignore_rules[]`, `tracked_junk_patterns[]`, `verification_ignored_roots[]`.
- Optional class field `retained_receipt` `{root, identity}`: allowed only when authority is immutable-receipt and disposition is retain. When the class pathspecs match zero tracked files, the validator emits `REJECT: retained receipt: <root> must not be archived (<identity>)` in place of the stale-class line. This is the mechanical guard that keeps the Phase 133 receipt directory unarchivable while every other phase directory can be archived without a red (amended D-135-02, D-135-03). The receipt path in scripts/ci/verify_nightly_run.sh is not changed (D-135-03).
- Class: `id`, `pathspecs[]` (git pathspec magic `:(glob)` and `:(exclude)`), `authority` (hand-authored | generated | tool-lockfile | history | immutable-receipt | third-party | fixture | agent-tooling), `consumer[]` (tracked paths), `package` (shipped | excluded), `disposition` (retain | delete | ignore), `reason`, and for generated classes `regenerate` `{commands[], drift_paths[], drift_check: "hygiene" | "none"}`; `drift_check: "none"` needs a reason (for example generators that need `npm ci`). A `delete` class may have an empty consumer list; it marks a tracked path awaiting removal, and `--require-settled` rejects any delete class (used by the closure plan).
- Vetted drift_check hygiene commands, pinned in the validator: `node brandbook/src/tokens-build.mjs`, `node brandbook/src/admin-css-build.mjs`, `node brandbook/src/sync-admin-css.mjs`.
- ignore_rule: `file` (tracked .gitignore path), `rule` (exact effective line), `produced_by`, `disposition: "ignore"`.
- CLI: `validate_artifact_ledger.sh --ledger FILE --offline [--require-settled] [--root DIR]`. Exit 0 ok, 1 REJECT lines on stderr (all reasons, sorted), 64 usage. bash 3.2, jq 1.6.
