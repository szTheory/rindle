- Shard file: `{"schema": "rindle-live-residue-allowlist-v1", "area": "<area>", "entries": [{"path", "class", "text", "count", "reason_class", "reason"}]}`. `text` is the line with leading/trailing whitespace trimmed and internal whitespace runs collapsed. For `path-name` hits `text` is the path itself.
- Classes (patterns built from string fragments so the scanner never matches itself; regexes are the RESEARCH "Classes, patterns and measured counts" table plus):
  - `path-name`: a scoped tracked path whose segments match phase or plan numbering (`phase_132_`, `phase_133_`-style).
  - `mojibake`: evaluated on the decoded UTF-8 text, never on raw bytes: U+FFFD; a text file that is not valid UTF-8; U+00C3 (`Ã`) or U+00C2 (`Â`) immediately followed by a code point in U+0080 to U+00BF; and U+00E2 U+20AC (`â€`, the Latin-1 rendering of a UTF-8 punctuation lead). Correctly encoded accented letters such as U+00E9 (`é`) and typographic dashes or quotes never match.
  - `duplicated-prose`: a word 4-gram of alphabetic tokens of length 3 or more, with at least 4 distinct words and not stopword-only, repeated within two adjacent comment lines.
  - `narration`: the closed phrase list `previously|formerly|used to (be|do)|was changed to|now we|has been (renamed|moved|removed|replaced)|for now|no longer`, comment lines only (`#`, `//`, `*`, `/*`, `<%!--`, `<!--`).
  - `artifact-comment`: comment lines naming agent or generator artifacts from a closed list (`generated by` followed by an AI or agent tool name, `ai-generated`, `as an ai language model`, GSD write sentinels, and bare `TODO|FIXME|XXX|HACK` words).

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-135-01 | Tampering | live_residue_allowlist shards | high | mitigate | Entries keyed by path, class and text with exact counts; stale or grown counts fail; no directory entries; area check; closure plan asserts zero pending-removal |
